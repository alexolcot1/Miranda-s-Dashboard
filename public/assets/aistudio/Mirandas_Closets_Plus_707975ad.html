Copias de seguridad y privacidad

Guarda una copia de tus datos y comprende dónde se almacenan.

Privacidad: esta aplicación está diseñada para funcionar localmente en tu navegador. No contiene analítica, anuncios ni scripts externos y no envía automáticamente tu inventario, ventas, facturas o recordatorios a ningún servidor. Los enlaces de la sección fiscal solo abren la web oficial si tú los pulsas.
Límite de seguridad: los datos de esta versión se guardan en el almacenamiento local del navegador y no están cifrados por una contraseña propia de la aplicación. La persona que consiga desbloquear tu tableta y usar el mismo navegador/perfil podría acceder a los datos. Protege la tableta con bloqueo de pantalla, no compartas el archivo HTML ni las copias de seguridad y no borres los datos del navegador sin exportar primero una copia. Abrir el archivo en otro navegador/dispositivo puede mostrar una base de datos distinta.

Exportar copia completa

Descarga un archivo JSON con productos, ventas, compras, gastos y tareas. Es la copia que debes guardar en un lugar privado.

Restaurar una copia

Importar una copia sustituirá todos los datos actuales de esta aplicación. Haz una copia antes de restaurar.

Exportar tablas para hojas de cálculo

¿Qué es CSV? Es un archivo de texto que organiza los datos en filas y columnas. Puedes abrirlo con Excel o importarlo en Google Sheets para filtrar, ordenar o sumar tus registros. No guarda el diseño de la aplicación ni reemplaza las facturas oficiales. En esta aplicación se exporta con punto y coma para adaptarse mejor a la configuración habitual en español.

Consejos para mantener los datos privados

1. Mantén un PIN o contraseña fuerte de bloqueo de la Xiaomi Pad 6.
2. Evita compartir el archivo HTML y las copias JSON/CSV; pueden contener información comercial.
3. Guarda una copia en una ubicación que controles y que no esté compartida públicamente.
4. Los datos del navegador pueden borrarse si limpias almacenamiento o reinstalas aplicaciones; exporta copias periódicas.
5. Esta página no es un sistema contable homologado ni almacena los PDF/fotos de las facturas: conserva los documentos originales aparte.
